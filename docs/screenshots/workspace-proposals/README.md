# Workspace layout references

These are browser-rendered visual proposals for Home, Asset Viewer, Modding,
and the separate Level Editor window. They are not captures of the Iced app.
Names, counts, geometry, conflicts, socket calibration, and some editor
controls in the reference images are illustrative; do not interpret them as
verified game data or as evidence of implemented behavior.

The Level Editor image uses a Tutorial screenshot as an illustrative viewport
backdrop while the mock outliner describes an Orbital Drill example. Actual
map selection, source verification and preview rendering must come from the
application's imported data rather than this reference image.
